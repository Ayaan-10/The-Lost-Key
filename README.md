# LostKeys

I made this game about a very small guy having a very inconvenient day. He goes out to get milk, trips, and loses his key. A potion master shrinks him so he can go looking for it, and the trail leads through a sewer to a rat who isn't giving the key back without a fight.

## Play

The browser version is here:

[Play LostKeys](https://ayaan-10.github.io/The-Lost-Key/)

Use **A/D** or the **arrow keys** to move, and **Space** to jump. In the rat fight, press **J** or click to throw your wing. Press **E** or click near the key to interact. Press **R** to restart.

## About the game

LostKeys is a small 2D platform game made in Godot 4.7. It starts on the street, continues through a sewer with ladders and hazards, and ends with a rat boss fight. The rat uses ground slams, rolling attacks, and acid drops, so watch the warnings and jump or move clear. Beat it, pick up the key, and you've got it back.

## Run it yourself

1. Install Godot 4.7.
2. Clone or download this repository.
3. Import `project.godot` in Godot and run the project.

The repository also includes a web export in `web-export/`.
